题库说明

结构：42 个情境母题，每个母题带 2–5 个语气版本（礼貌 / 冷淡 / 不耐烦 / 命令 / 教育 / 讽刺 / 无礼 / 着急无恶意 / 真诚道歉 / 反咬你敏感 / 拉大家站队 / 当众调侃），叠加关系距离、环境、你的当时状态随机组合，可持续生成不重复的版本。
每个情境都拆成两栏：「场景里明确发生的」与「此刻仍然不知道的」——后者不替你判断，只留给你自己分辨。
五种行动档位：先不回应 / 询问发生了什么 / 表达一个边界 / 配合但保留选择 / 离开·暂停。每档对应对方不同的下一句。
不做的事：不设标准答案，不评判对错，不把生气当成失败，也不鼓励用羞辱与攻击保护自己。目标只有一句：我可以有任何情绪，但逐渐拥有更多选择。
