放映室使用说明

1. 点击「选择影片」加载本地视频，支持 mp4 / mkv / webm 等格式。

2. 右侧「AI 陪伴」面板显示 AI 和你自己的消息；下方标签可切换「时间轴 / AI生成 / 截图分析 / 观影记录」。

3. 「AI生成」建议先「上传字幕」(.srt/.vtt)，AI 会基于真实时间轴写评论；没字幕也可粘贴剧情文本。填好 API Key 后一键生成。

4. 播放时，到点的 AI 评论会自动出现在上方陪伴面板；你也可以直接在输入框打字或点 🎤 说话，AI 会结合当前播放位置真实回复（不再只是罐头话）。

5. 「截图分析」上传电影截图，AI 会基于画面内容发表看法。

6. 「观影记录」里每部电影都有海报、标题、观看日期和进度；点记录可联网搜索海报或手动上传。
