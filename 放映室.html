AI 是怎么「看」电影的？
这里用的是「剧情文本预读」方案：你把剧情/字幕给 AI，它提前写好每个时间点该说什么。播放时到点自动显示在下方面板。不需要实时截图，成本低、响应快。如果想做实时画面分析，需要调用多模态模型（费用高很多），可以先在「AI配置」里填接口尝试。

放映室使用说明

1. 点击「选择影片」加载本地视频，支持 mp4 / mkv / webm 等常见格式。

2. 在右侧「AI生成」粘贴剧情简介或字幕，填写 API Key 后生成时间轴评论。

3. 播放时到达对应时间点，AI 的评论会显示在下方「AI 陪伴」面板，不会遮挡画面。

4. 你也可以在时间轴里手动添加自己的评论或备注。

5. 观影记录、影片信息、时间轴评论都会自动保存在本地浏览器里。
